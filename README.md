# Control de empleados — versión corregida

Correcciones: fecha local de Argentina; actualización de la pantalla correcta al marcar tareas realizadas o pendientes; acceso explícito a campos de asignación y temperaturas.

Incluye empleados, tareas, horarios, temperaturas, historial e informe diario.

## Abrir en Android
Extrae el ZIP y abre `index.html` en el navegador. Los datos se guardan localmente en ese navegador y dispositivo.

Nota: esta versión sigue siendo una aplicación web, no un APK nativo. La carga de fotografías de respaldo todavía debe añadirse.
