CONTROL DE EMPLEADOS — versión inicial desde cero

Proyecto Android nativo con almacenamiento local mediante SharedPreferences.
Funciones iniciales: navegación principal, 6 empleados con nombres editables, lista de tareas por empleado, estado pendiente/realizada persistente, registro de entrada/salida y resumen de informes.

Para compilar en GitHub Actions:
1. Subir el contenido de esta carpeta al repositorio (incluida .github/workflows/build.yml).
2. Abrir Actions > Generar APK Android > Run workflow.
3. Al finalizar, abrir la ejecución y descargar el artefacto Control-de-empleados-APK.

Esta primera versión no requiere Internet durante el uso. Fotos, asignación personalizada de tareas y exportación avanzada de informes quedan para la siguiente etapa.
